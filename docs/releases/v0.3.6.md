# Wormhole Observatory v0.3.6

First public release of Wormhole Observatory, a desktop and headless management
application for Pi-hole v6 with local domain intelligence, structured evidence
collection, optional LLM-assisted classification, conservative automation, and
review workflows.

## Highlights

- Multi-instance Pi-hole v6 management with exact rules, regex/list views,
  groups, conflict detection, audit history, and rollback.
- Evidence-oriented domain review with provenance, source-quality scoring,
  contradiction detection, freshness policies, and citations.
- Optional LLM provider pools with quota-aware scheduling, structured result
  validation, and provider-native browsing support where available.
- Protected-service profiles, manual tags, dependency graphs, and historical
  behavior-change detection.
- Authenticated local HTTP API, responsive web UI/PWA, ntfy/UnifiedPush review
  notifications, and LAN/Tailscale operation without a required public cloud.
- Reproducible Windows and Linux Onedir builds plus a persistent
  multi-architecture container and Home Assistant App metadata.

## Security and release trust

- OS credential-store integration for supported secrets.
- Verified TLS by default with optional custom CA bundles; insecure TLS
  disablement is rejected.
- Explicit least-privilege GitHub Actions permissions and immutable third-party
  Action references.
- CodeQL, Dependency Review, Dependabot, and Secret Scanning release gates.
- Keyless Sigstore signing, portable in-toto/SLSA provenance, and GitHub Artifact
  Attestations for desktop release archives.
- Multi-architecture container builds with SBOM and provenance on publication.
- AGPL-3.0-only project licensing with preserved upstream and third-party notices
  in source and binary distributions.

## Compatibility validated for this release candidate

- Python 3.11, 3.12, and 3.13.
- Pi-hole FTL 6.3, 6.5, and 6.6.
- Container platforms: linux/amd64 and linux/arm64.

## Notes

- This is a pre-1.0 release; Simulation mode is recommended for the first live
  deployment.
- Some internal package, entry-point, archive, and build-path identifiers still
  use the historical `pihole-manager` / `Pi-Hole-Manager` working name for
  compatibility. The product name is Wormhole Observatory.
- No public cloud is required for normal local/headless operation; external
  evidence and LLM providers are optional and depend on configured sources.
- Wormhole Observatory is not an official Pi-hole project and is not affiliated
  with or endorsed by the Pi-hole project.
