# Wormhole Observatory v0.3.7

Patch release correcting the desktop startup regression discovered by the post-publication smoke test of v0.3.6.

## Fixed

- The desktop application no longer crashes while constructing the Notifications settings page. An application-state attribute had shadowed Tkinter's internal `_options()` method, causing `pack()` to fail during Settings initialization.
- The release pipeline now smoke-starts both the source GUI in CI and the packaged Linux GUI before signing or publishing release artifacts.
- A static regression test rejects settings-page instance attributes that shadow callable Tkinter widget members.

## Server and container status

The headless Docker/API/PWA runtime was not affected by the Tkinter-only startup defect. The same server architecture remains in place: persistent multi-architecture container images, authenticated HTTP API, responsive review PWA, LAN/Tailscale access and Home Assistant App metadata.

## Release trust

As with v0.3.6, Windows and Linux desktop archives must pass reproducibility checks, Sigstore verification, portable provenance and GitHub Artifact Attestations before publication. The container publication remains multi-architecture with SBOM and provenance.
